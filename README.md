# 🎵 Spotify Web Player Clone

A frontend Spotify Web Player clone built using **HTML and CSS**.  
This project recreates the look and feel of Spotify's web player with a responsive layout, sidebar navigation, music cards, and a fixed music player interface.

## 🚀 Features

- 🎧 Spotify-inspired music player UI
- 🏠 Home and Library sidebar
- 🎵 Music/playlist cards
- 📱 Responsive layout
- ▶️ Music player control section
- 🔊 Volume and playback controls UI
- 📌 Sticky navigation bar
- 🎨 Dark Spotify-inspired interface
- ✨ Hover effects and interactive UI elements

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **Font Awesome**
- **Google Fonts – Montserrat**
